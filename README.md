# GitHub Pages root redirect

https://smokingelephants.github.io/ redirects immediately to
https://smokingelephants.github.io/academic-homepage/.

The academic homepage is maintained in the separate
[academic-homepage repository](https://github.com/smokingelephants/academic-homepage).

GitHub Pages serves this repository’s `main` branch from the root directory.

## Hilbert Meadow

The static Godot WebAssembly build is served at
https://smokingelephants.github.io/games/hilbert-meadow/
and linked from the academic homepage. The root redirect stays in place.
All generated files in the game folder must be updated together.
